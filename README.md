# glass-dots

Arch + Hyprland в стиле **Material 3 Expressive + матовое стекло**. Все цвета — из обоев
через [matugen](https://github.com/InioX/matugen) и меняются на лету.

![рабочий стол](assets/desktop-182723.png)

## Что внутри

- **Бар на Quickshell** — рабочие столы, запущенные приложения, часы, погода, плеер в стиле Google,
  раскладка, громкость (с выбором устройства вывода), меню питания, «динамический остров».
- **Выбор обоев и темы** — картинки, GIF и видео (mpvpaper); под обоями — кружки цветов, найденных
  на обоях: выбираешь, от какого цвета строить тему (как «Обои и стиль» на Pixel).
- **Тема везде**: Hyprland, kitty, rofi, btop, GTK, Dolphin/Qt (цветовая схема KDE + папки Papirus в цвет).
- **Скриншоты** — выделение со скруглёнными углами и свечение по краям экрана в стиле Gemini.
- **Покрути мышкой по кругу** → по краям вырастают чёрные рамки → выделяешь область → она уходит в Google Lens.
- **Экран входа SDDM** — часы, дата, погода, те же обои (и видео) и цвета, пароль рисуется
  фигурами Material 3 Expressive.


## Оболочка glass

- **Экран блокировки** — обои рабочего стола (видео тоже), часы, погода; пароль рисуется фигурами
  Material 3, как на Pixel. `Super+Esc`, кнопка в шторке, после AOD и перед сном.
  Вместо SDDM: `./lockscreen-instead-of-sddm.sh` (вернуть — `--undo`).
- **Always On Display** — семь циферблатов (формы, стрелки, орбита, точки, планеты, горизонт, сегменты),
  окна на это время гаснут.
- **Остров** — часы (клик — календарь), погода (клик — прогноз), плеер, уведомления, таймер
  (`timer 5m чай` в лаунчере), эквалайзер по настоящему звуку (cava).
- **Бар** — рабочие столы, док с подписями, системный трей, раскладка, громкость, шторка с нагрузкой
  на процессор, память и видеокарту; защита глаз умеет включаться сама от заката до рассвета.
- **Лаунчер** — приложения, открытые окна, калькулятор, эмодзи, пипетка, команды оболочки.
- **Шпаргалка по клавишам** — `Super+/`, читается прямо из `hyprland.conf`.
- **Уведомления не пропадут даже в игре** — нашлась катка в Dota 2, а ты на другом столе или отошёл:
  уведомление всё равно придёт.
- **Стекло** — матовое, с сильным блюром (сила — в настройках), или тональные поверхности Material.
- **Виджеты на рабочем столе** — 15 штук в духе Pixel: коротко о главном, часы (любой из 7 циферблатов AOD),
  погода, прогноз, музыка, календарь, поиск, частые приложения, быстрые кнопки, система, таймер, заметка,
  солнце, фото, «день и год». Правый клик → «Изменить виджеты»: обои закрывают окна и расфокусируются,
  проявляется сетка светящихся точек; виджеты переносятся и меняют размер за ручки по краям, раскладка
  подстраивается под размер. «Настроить» у каждого виджета — как на Samsung: фон (размытие, цвет или без фона),
  цвет темы, прозрачность, стиль (циферблат, форма фото, период). Размытие — своё, гладкое, без зерна.
- **Фон под окнами** (лаунчер, настройки, шпаргалка) — светящиеся точки без сетки или просто затемнение:
  Настройки → Оформление → «Фон под окнами». Точки запечены в текстуру (`shaders/make-dots.py`) и почти не грузят.

## Ассистент — Вега

Позови **«Вега»** (или Super+A) и скажи, что нужно, — можно и «Какая погода, Вега?»; Super+Space → «?» —
текстом. Отвечает голосом и делает: включает и переключает музыку («включи металлику» сразу играет в
Spotify), громкость, яркость, ночной режим, «не беспокоить», Wi-Fi, Bluetooth; открывает и закрывает
приложения и сайты, вкладки браузера, окна и рабочие столы; скриншоты, запись экрана, блокировка, обои;
время, дата, погода, загрузка процессора и видеокарты, память, диск, что играет; таймеры, напоминания,
будильник; выключение, перезагрузка, сон — после «да». После ответа слушает продолжение без имени;
«хватит» — конец разговора. Пока говорит — позови «Вега», и она замолчит и выслушает. «Запомни …» / «забудь …» — долгая память.

Отвечает локальная модель Gemma 4 E4B (llama.cpp на видеокарте): частые команды — по шаблонам, мгновенно,
остальное — модель, ~0,4 с. Сложный вопрос — начни со слова **«морковь»** («Вега, морковь, почему небо
синее?»), набери «??» в лаунчере или нажми **Super+Alt+A** — эта фраза уйдёт в Claude по API, ответ
откроется в лаунчере. Речь распознаёт Whisper large-v3-turbo, отвечает голосом Silero — всё локально.

В настройках оболочки, раздел «Ассистент»: строка «Голос» открывает поверх выбор из 9 голосов —
переключатель «Русские / English» (русские Silero: Шёлк, Мята, Карамель, Бархат, Гранит; английские Piper:
Honey, Heather, Graphite, Smoke — с ними Вега отвечает по-английски) и ползунки тона (мягче ↔ твёрже),
скорости и высоты, превью звучит прямо на ходу. Там же — громкость системы при вызове (35 %), имя, ответ
голосом и «Расширенные»: модель Claude, «где думать», пауза в конце фразы, разговор без имени. «Найди в
интернете …» — находит и отвечает (DuckDuckGo, Википедия).

```bash
./assistant/setup.sh                 # окружение, модели (~6,5 ГБ), whisper.cpp с CUDA, служба systemd --user
$EDITOR ~/.config/glass/assistant.env  # ANTHROPIC_API_KEY=… — только для «морковь» (console.anthropic.com → API Keys)
systemctl --user restart glass-assistant
```

Нужен `llama-server` (AUR: `llama.cpp-cuda`). Локальная модель держит ~3,3 ГБ видеопамяти: грузится, когда
зовёшь, выгружается через 30 минут тишины и при запуске игры; мало памяти — частично на процессоре.
Spotify: без ключей исполнитель находится через Wikidata; с ключами приложения Spotify
(`SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` в `assistant.env`) — точнее, и треки тоже.

Из терминала (в `~/.local/share/glass-assistant/app`): `python -m glass_assistant ask "вопрос"`,
`… claude "вопрос"`. Тесты: `cd assistant && python -m unittest discover -s tests`; на живой модели —
`python -m tests.eval_local`.

## Установка

```bash
git clone https://github.com/makaka393/glass-dots ~/glass-dots
cd ~/glass-dots && ./install.sh
```

Установщик ставит пакеты (pacman + yay/paru для AUR), раскладывает конфиги в `~/.config`
(старые — в `~/.config-backup-<дата>`), ставит тему SDDM и применяет первую тему.
Обои клади в папку из `config/quickshell/glass/Theme.qml` (`wallpaperDir`).

Город для погоды — `lat`/`lon` в `Theme.qml`.

## Горячие клавиши

```
bind = $mainMod, SPACE, exec, rofi -show drun
bind = SUPER SHIFT, S, exec, ~/.config/hypr/scripts/screenshot.sh region
bind = $mainMod, W, exec, qs ipc -c glass call picker toggle
bind = SUPER SHIFT, A, exec, ~/.config/hypr/scripts/screenshot.sh pretty
bind = , Print, exec, ~/.config/hypr/scripts/screenshot.sh full
bind = SUPER SHIFT, G, exec, ~/.config/hypr/scripts/screenshot.sh lens
```

## Настройки

| что | где |
|---|---|
| схема / контраст / тёмная-светлая | `~/.config/hypr/scripts/theme.env` |
| сменить обои из терминала | `changetheme.sh <файл> [#цвет]` |
| жест «покрути мышкой» | начало `~/.config/hypr/scripts/shake-lens.py` (CIRCLES, START, NO_FULLSCREEN) |
| толщина чёрных рамок жеста | `~/.config/quickshell/glow/shell.qml` (`shell.shake * N`) |
