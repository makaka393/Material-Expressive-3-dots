# Вега — roadmap

Ассистент оболочки glass: локальная модель (Gemma 4 E4B) по умолчанию, Claude — по слову «морковь».
Главная метрика — скорость ответа; всё новое проверяется eval'ом локальной модели (`tests/eval_local.py`).

## Сделано (октябрь 2026)

- Имя «Вега», слово-активатор с подсказкой Whisper; перебить по имени, пока говорит.
- Голоса: 5 русских Silero, 4 английских Piper (с ними отвечает по-английски); тон, скорость, высота.
- «Найди в интернете» — находит и отвечает (DuckDuckGo, Википедия).
- Знает, что установлено (`system_info` → `apps`), к файлам доступа нет.
- Микрофон для дальнего голоса: WebRTC — шумодав, автоусиление, эхоподавление (`glass-vega-mic`).
- Громкость 35 % при вызове, главный тумблер, болгарскую музыку не включает.

## Дальше — по порядку

1. **Дальний микрофон вживую.** Позвать с другого конца комнаты, по журналу (`wake: похоже на имя…`)
   подстроить порог речи и варианты имени. Если не хватит — ближе к столу микрофон или второй.
2. **Погода в любом городе.** Сейчас `system_info` отвечает только про свой город («погода в Токио» — нет).
3. **Голос F5 (решение за Ромой).** Звучит лучше всех, но не влезает в 8 ГБ видеопамяти рядом с Gemma и
   Whisper: либо Gemma частично на процессоре (+1,5–2 с к ответу), либо Whisper поменьше, либо удалить (9 ГБ).
4. **Файлы — только чтение.** Найти и открыть файл в Загрузках, Документах, Изображениях; без удаления и
   перемещения. Потом, если понадобится, — изменения с подтверждением голосом.
5. **Spotify с входом.** Свои плейлисты, «лайкни трек», «что я слушал» — нужен вход OAuth (ключи уже есть).
6. **Уведомления.** «Что пришло?» — прочитать последние уведомления оболочки. Ответить в Telegram — только
   с подтверждением перед отправкой.
7. **Память в настройках.** Список того, что Вега запомнила, — посмотреть и удалить руками.
8. **Claude по ключу.** Когда будет ключ API — проверить «морковь» и голосовые ответы Claude в лаунчере.
