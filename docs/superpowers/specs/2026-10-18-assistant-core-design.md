# Ассистент glass, этап 1: ядро — локальная модель по умолчанию, Claude по слову, инструменты

Дата: 2026-10-18. Ветка: `worktree-shell-visual-review`. Код: `assistant/`, оболочка: `config/quickshell/glass/`.

## Зачем

Сейчас ассистент только разговаривает: главный — Claude по API, локальная Qwen3.5-9B — запасная,
когда Claude недоступен. Пользователь хочет наоборот:

- по умолчанию отвечает **локальная модель** — быстро, без сети, и **делает мелочи на компьютере**
  (переключить трек, громкость, яркость, ночной режим, «не беспокоить»; дальше — больше, этапы 2–4);
- **ключевое слово** («морковь») в начале фразы отправляет **эту одну фразу** в Claude по API —
  для сложных вопросов;
- звать и голосом (Super+A, слово-активатор), и текстом (лаунчер, «?»).

Главная метрика — время от конца фразы до действия. Цель: действие < 0,5 с после распознавания.

## Что выяснил этап 0 (спайк, 80 русских фраз, Whisper загружен)

- Модель: **gemma-4-E4B-it Q4_K_M** (unsloth): 49/50 простых и 27/30 сложных фраз, 0,29 с медиана
  до готового вызова, 76 ток/с, 3,3 ГБ видеопамяти. Qwen3.5-4B медленнее и слабее и вызвала
  `power(shutdown)` на «как выключить компьютер в линуксе»; Qwen3.5-9B в видеопамять не влезает (3,5 с).
- llama-server — с `-ngl 99 -fit off`: `--fit` оставлял слои на процессоре, втрое медленнее.
- Длительности — частями (`hours`, `minutes`, `seconds`): модель не умеет «полтора часа = 5400 с».
- Иногда модель отвечает «Блокирую экран» без вызова. Лечится повтором с `tool_choice: "required"`
  (+0,65 с только в этом случае). Строгое правило в промпте делает хуже — модель пишет вызовы текстом.
- Модель повторяет в ответе метку `[дата, время]` из сообщения — срезать.

## Решения

| Вопрос | Решение |
|---|---|
| Слово-активатор | «Обсидиан» (вместо «гласс/ассистент/джарвис»), включено. «Обсидиан, выкрути яркость…» — локально; «обсидиан, морковь, …» — Claude. |
| «Морковь» | Действует на одну фразу. Следующая — снова локально. Узнаётся по началу «морков…» — «морковь», «морковка», «морковку». |
| Ответ Claude | Открывается окно с ответом (карточка ассистента в лаунчере) сразу, как только ясно, что отвечает Claude (событие `route`); голосом — ещё и озвучка. Ответы локальной — как раньше, в острове. |
| Локальная не справилась | Отвечает сама, хотя бы примерно («от 70 до 150 тысяч»). Сама в Claude не отсылает: «спроси у Claude» от неё раздражало — так она отвечала на всё (2026-10-18, отзыв пользователя). Нужен Claude — «морковь»; одно слово «морковь» сразу после ответа отправляет прошлый вопрос. Подходящего инструмента нет — «Пока так не умею», без чужого действия. |
| Claude недоступен (нет ключа/сети) | «Claude недоступен — отвечаю сама:» и ответ локальной модели. |
| Claude и действия | Claude получает те же инструменты (кроме `suggest_claude`). |
| Настройка `backend` | Старые значения остаются: `auto` — локально + Claude по слову (по умолчанию); `claude` — всё в Claude; `local` — Claude никогда. Миграция не нужна. |
| Локальная модель в памяти | Грузится заранее: при Super+A, при слове-активаторе, при входе в режим «?» лаунчера (2 с — прячется за речью). Выгружается после 30 мин простоя и при запуске игры (gamemode). |

## Архитектура

```
Super+A / слово / лаунчер ──► daemon.ask(text, voice, to)
                                   │
                              router.route()  ── «морковка …» / to=claude / backend=claude ──► ClaudeBrain
                                   │                                                              │
                                   ▼                                                              │
                              LocalBrain (llama-server, Gemma 4 E4B)                              │
                                   │  tool_calls                                                  │ tool_use
                                   ▼                                                              ▼
                              tools.run(name, args) ◄─────────────────────────────────────────────┘
                                   │  Result(ok, show, say)
                                   ▼
                     события в сокет: action / delta / done ──► Assistant.qml ──► остров, лаунчер
                     озвучка say (если спрошено голосом)
```

### Модули (`assistant/glass_assistant/`)

- **`router.py`** — `route(text, cfg, to=None, last=None) -> Route(brain, text, escalated)`.
  Слово ищется в первых трёх словах фразы, по началу слова (как `after_wake`: первые
  `max(4, len-1)` букв — «морковк…» ловит падежи и огрехи распознавания). Остаток после слова —
  вопрос. Пустой остаток → `escalated=True`, вопрос = `last` (последний вопрос локальной модели не
  старше 2 мин); если его нет — `Route(brain="claude", text="")`, демон слушает вопрос (голос) или
  отвечает ошибкой «Что спросить у Claude?» (текст). `to="claude"` и `backend="claude"` → Claude
  всегда; `backend="local"` → слово не действует. Чистая функция, без ввода-вывода.
- **`tools/`** — реестр инструментов.
  - `base.py`: `Tool(name, description, params, required, handler, claude=True)`,
    `Result(ok, show, say=None)` (`show` — короткая строка для острова/лаунчера, всегда;
    `say` — что произнести голосом, `None` — молча: смена трека слышна сама),
    `sh(*argv, timeout=5)` — запуск без shell, ошибка при ненулевом коде,
    `qs(target, fn, *args)` — `qs ipc -c glass call …`, возвращает stdout.
  - `__init__.py`: `TOOLS` (имя → Tool), `openai_tools()`, `anthropic_tools()` (без `claude=False`),
    `async run(name, args) -> Result`: неизвестный инструмент, лишние/неверные аргументы → `Result(ok=False)`;
    числа из строк приводятся; таймаут 5 с; исключение → `Result(ok=False, show="Не получилось: …")`.
  - Этап 1 — инструменты:
    - `media(action: play|pause|toggle|next|previous|seek_forward|seek_back, seconds)` — `playerctl`
      (`play-pause`, `position 30+`/`30-`);
    - `volume(level, change, mute)` — `wpctl set-volume -l 1.0 @DEFAULT_AUDIO_SINK@ 40%|10%+|10%-`,
      `set-mute 1|0`; `show` — итоговая громкость (`wpctl get-volume`);
    - `brightness(level, change)` — через оболочку: новый `IpcHandler` в `Brightness.qml`
      (`set(v)`, `change(d)`, оба возвращают итог) — ползунок и DDC/гамма остаются в одном месте;
    - `night_light(on)` — `qs ipc … night enable|disable`;
    - `do_not_disturb(on)` — новая функция `set(on)` в IPC `notifs` (сейчас есть только переключатель);
  - Описания инструментов — из спайка (там подобраны: «включи музыку» без названия → `media play`,
    «скип» → `next`).
- **`local.py`** — `LocalServer` (llama-server по требованию: `-ngl 99 -fit off -c 8192 -np 1 -fa auto
  --jinja --reasoning off --no-webui`; не поднялся — повтор с `--fit on`, медленнее, но работает;
  `warm()`, `unload()`, выгрузка после `local_idle_min`) и `LocalBrain.answer(text, voice, on_delta)
  -> Reply(text, actions, suggest)`:
  1. сообщения: системный промпт (постоянный — кэшируется llama-server) + история (последние
     `local_history_turns`=6 реплик, не старше 2 мин, в формате OpenAI с `tool_calls` и `tool`) +
     вопрос с меткой времени;
  2. потоковый запрос; текст идёт в `on_delta` (с вырезанной меткой `[…]` в начале), вызовы
     собираются из кусков;
  3. есть вызовы → `tools.run` по порядку; ответ = `say`/`show` результатов; **второго прохода модели
     нет** — ради скорости;
  4. вызовов нет, а текст начинается с «блокирую/включаю/выключаю/ставлю/открываю/…» → один
     повтор с `tool_choice: "required"`, текст отбрасывается.
- **`claude.py`** — нынешний код Claude из `llm.py` (поток, Opus 5.5, effort, server-side fallback,
  кэш промпта, история с блоками) + инструменты: `stop_reason == "tool_use"` → выполнить, вернуть
  `tool_result`, продолжить (до 5 кругов). Своя история, как сейчас (Claude помнит прошлые
  «морковки» в пределах `history_idle_min`).
- **`llm.py`** — удаляется (разнесён в `local.py` и `claude.py`).
- **`daemon.py`** — `ask(text, voice, speak, to)` → `route` → мозг; `listen(to)`; новые команды
  `warm`, `unload`; `last_local` (вопрос + время) для «морковки» без текста; после слова-активатора
  фраза тоже идёт через `route`.
- **`config.py`** — новые ключи: `claude_words: ["морковь"]`, `wake_words: ["обсидиан"]`, `local_model` → Gemma,
  `local_idle_min: 30`, `local_history_turns: 6`.

### Протокол сокета (дополнения, старое не меняется)

- клиент → служба: `{"cmd":"ask", …, "to":"claude"}`, `{"cmd":"listen","to":"claude"}`,
  `{"cmd":"warm"}`, `{"cmd":"unload"}`;
- служба → клиенты: `{"ev":"route","brain":"local|claude","text":"…"}` — до ответа, кто отвечает;
  `{"ev":"action","name":"media","args":{…},"ok":true,"show":"Следующий трек"}`
  на каждый вызов; в `done` — `"backend":"local|claude"` (как сейчас) и `"actions":[…]`.

### Оболочка

- `Assistant.qml`: `listenClaude()`, `askClaude(text)`, `warm()`, `unload()` + те же в `IpcHandler`;
  на `route` с `brain:"claude"` — открыть лаунчер с карточкой ответа (без нового вопроса);
  свойство `actions` (из событий `action`) для карточек; в `cfg` — `claudeWords`.
- `LauncherContent.qml`: «??текст» → Claude; при входе в режим «?» — `Assistant.warm()`; подпись
  «ответила локальная модель · Qwen3.5» → «Gemma 4»; результат действия — строкой `show` с иконкой.
- `DynamicIsland.qml`: если ответ — только действия, показать их `show` (например «Следующий трек»).
- `SettingsContent.qml`: подписи `backend`: «Локально, Claude по слову» / «Всегда Claude» /
  «Только локально»; строка «Слово для Claude: «морковка»».
- Клавиши: Super+Shift+A → `qs ipc -c glass call assistant listenClaude` (`hyprland.lua` и
  `hyprland.conf`); `gamemode-start.sh` → `qs ipc -c glass call assistant unload`.
- `Brightness.qml` и `Notifs.qml` — новые IPC-функции (см. инструменты).

### Установка

`assistant/setup.sh`: качать Gemma 4 E4B вместо Qwen3.5-9B; флаг `--no-local` убрать (локальная
теперь главная). README — раздел ассистента под новую схему.

## Ошибки

- llama-server не поднялся и после `--fit on` → `error` «Локальная модель не запустилась (см.
  logs/llama-server.log)»; если есть ключ — ответить через Claude с пометкой.
- Инструмент упал → `action` с `ok:false` и `show` «Не получилось: …»; голосом — то же.
- Модель вызвала неизвестный инструмент или с плохими аргументами → как ошибка инструмента.
- Claude недоступен → см. «Решения».
