# Ассистент glass, этап 2–3: «обсидиан», полный набор навыков, голос, анимация

Дата: 2026-10-18. Ветка `worktree-shell-visual-review`. Продолжение `2026-10-18-assistant-core-design.md`.

## Зачем

Пользователь: «обсидиан» в микрофон → ассистент слушает, распознаёт, делает что угодно на компьютере
(открыть приложение, сменить музыку, выбрать другую — «фулл работа с компом»), отвечает голосом;
пока он работает — анимация («придумай от себя, потом подправим»). Claude настроим позже; всё
ниже — на локальной Gemma 4 E4B.

## Слово-активатор

- Работает уже (этап 1, `wake: true`). Проверено синтезом Silero → Whisper: «обсидиан» узнаётся во
  всех 15 фразах, но Whisper иногда пишет **«Obsidian»** латиницей и оборачивает фразу в «…».
  → `wake_words: ["обсидиан", "obsidian"]` по умолчанию и в настройках пользователя; `strip_word`
  срезает кавычки «»"" по краям остатка.
- Сразу после «обсидиан» — **короткий звук** (два тона вверх, ~0,2 с): ассистент услышал. Без него
  непонятно, слушает ли он, если не смотришь на экран.

## Навыки (инструменты локальной модели и Claude)

| `info.py` | `system_info(kind)` | time, date, weather (open-meteo по lat/lon из `Theme.qml`), cpu (/proc/stat + k10temp), gpu (nvidia-smi), memory (/proc/meminfo), disk, headphones (upower/bluetoothctl), now_playing (playerctl). Ответ `say` — голосом. |

## Анимация — «орб»

Новый слой оболочки `AssistantOrb.qml`: внизу по центру экрана, над всем, клики проходят насквозь,
клавиатуру не берёт. Виден, пока ассистент занят (`Assistant.busy`) + плавно исчезает.

- Основа — фигура M3 Expressive (`MorphShape` + `material-shapes.js`) ~84 px цвета темы, без размытия
  (см. память «visual dislikes»).
- **Слушаю** (primary): «печенька» дышит — масштаб от громкости микрофона, на пиках морф круг ↔
  Cookie12; от фигуры расходятся 2–3 тонких кольца-волны.
- **Распознаю**: быстрые морфы Cookie4 → Clover4 → Pill, быстрое вращение.
- **Думаю** (tertiary): Sunny/Flower медленно вращается и дышит.
- **Говорю** (secondary): масштаб от громкости озвучки, на каждом слоге — морф к следующей фигуре.
- Появление/исчезновение — «пружинный» масштаб из 0 (как у острова), не прозрачность.

Остров и карточка ответа остаются как есть — орб только анимация.

## Ошибки

- Нет приложения — «Не нашёл приложение «…»». Нет окна — «Окна «…» нет». Нет плеера — как в этапе 1.
- Сеть для погоды/Spotify недоступна — «Не получилось узнать погоду» и т.п.
- Подтверждение питания истекло — молча забыть.

## Проверка

- Модульные тесты для каждого модуля с подменёнными `sh`/`qs`/`hyprctl`/файлами (как этап 1);
  `strip_word` (кавычки, «Obsidian»); подтверждение питания (да / нет / истекло / текстом);
  планировщик (срабатывание, сохранение, перезапуск); уровень озвучки.
- `eval_local.py` — фразы на все новые инструменты; цель ≥ 95 %, медиана < 0,5 с.
- Оболочка — копия на headless-мониторе: орб во всех состояниях (скриншоты).
- Живьём — безвредное: открыть/закрыть приложение, погода, время, таймер на 5 с.
